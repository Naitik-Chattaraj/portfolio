# Tech Club Website

The **official website** for the Tech Club of DPS Ruby Park, Kolkata — designed to be the digital home for all things tech at the school.

## What it does

- Showcases club events, workshops, and competitions
- Profiles active members and leadership
- Hosts downloadable resources and project showcases
- Features a responsive design that works across all devices

## Tech Stack

| Layer    | Technology         |
|----------|--------------------|
| Frontend | HTML, CSS, JS      |
| Hosting  | GitHub Pages       |
| Design   | Figma → Code       |

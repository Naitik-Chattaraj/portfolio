# The Vantage App

An **all-in-one productivity app** engineered for tracking complex tasks, managing creative workflows, and publishing articles seamlessly.

## Features

- Intuitive task management with prioritization, kanban, and scheduling
- Rich text article editing suite with real-time markdown preview
- Fast, distraction-free user experience tailored for writers and creators

## Tech Stack

| Layer | Technology |
|---|---|
| Platform | Web / Progressive Web App |
| Core | React, TypeScript, Tailwind CSS |
| State & Storage | Modern Local & Cloud Sync |

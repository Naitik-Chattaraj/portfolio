# The Carcino Foundation

The **official website** for **The Carcino Foundation** (2025–26) — dedicated to raising awareness, driving youth engagement, and supporting cancer care initiatives.

## Highlights

- Immersive interactive narrative highlighting community initiatives and outreach programs
- Clean, empathetic design system tailored for healthcare advocacy
- Responsive performance optimized across all modern mobile and desktop screens

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js, React |
| Styling | Tailwind CSS, Modern CSS |
| Media & Motion | GSAP, High-definition video storytelling |

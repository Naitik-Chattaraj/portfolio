# LuminoLens

The **award-winning website** developed for the **2025 Hackathon at DPS Ruby Park, Kolkata**, securing top honors for innovation, aesthetics, and technical execution.

## Highlights

- Immersive optical visualization experience with interactive light simulations
- Real-time WebGL / Canvas effects exploring luminosity and chromatic dispersion
- High-performance responsive layouts engineered under tight hackathon timelines

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, Next.js, HTML5 Canvas |
| Styling | Modern CSS, Tailwind CSS |
| Motion | GSAP ScrollTrigger, Custom Physics |
